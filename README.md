## Featured project

### [Planora India: product documentation](https://github.com/Prajyoth-dev/planora-india-product-documentation)

A complete product specification for a concept AI travel-planning and booking app for Indian travellers. It's a documentation project and contains no software.

| Area | What's in it |
|---|---|
| Requirements | PRD, FRD and SRD with permanent requirement IDs and acceptance criteria |
| Traceability | A requirements traceability matrix generated from the documents and checked by a script |
| Governance | Decision log, risk register, assumptions and open items, glossary |
| Delivery | Release plan, test strategy, soft-launch checklist |
| Research | Market research, competitor analysis and a source register |
| Outputs | Mermaid diagrams, plus PDF and Word exports of the key documents |
